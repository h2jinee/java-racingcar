# 자동차 경주 게임
## 진행 방법
* 자동차 경주 게임 요구사항을 파악한다.
* 요구사항에 대한 구현을 완료한 후 자신의 github 아이디에 해당하는 브랜치에 Pull Request(이하 PR)를 통해 코드 리뷰 요청을 한다.
* 코드 리뷰 피드백에 대한 개선 작업을 하고 다시 PUSH한다.
* 모든 피드백을 완료하면 다음 단계를 도전하고 앞의 과정을 반복한다.

## 온라인 코드 리뷰 과정
* [텍스트와 이미지로 살펴보는 온라인 코드 리뷰 과정](https://github.com/next-step/nextstep-docs/tree/master/codereview)

## 기능 목록

정책
- 각 자동차에 이름을 부여할 수 있다.
- 각 자동차의 이름은 5자를 초과할 수 없다.
- 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.
- 우승자는 한 명 이상일 수 있다.
- 자동차는 전진 또는 멈출 수 있다.
- 자동차는 0 에서 9 사이의 랜덤값을 구한 후, 랜덤값이 4 이상일 경우 전진한다.


## 단위 테스트

### 자동차 이름
- [ ] 자동차에 이름을 부여할 수 있다.
- [ ] 자동차 이름은 빈 문자열이나 null이 될 수 없다.
- [ ] 각 자동차의 이름은 5자를 초과할 수 없다.

### 자동차 위치
- [ ] 자동차의 초기 위치는 0이다.
- [ ] 두 위치 중 더 큰 위치를 반환할 수 있다.
- [ ] 두 위치가 같은지 비교할 수 있다.

### 자동차
- [ ] 자동차는 0에서 9 사이의 값 중 4 이상이면 전진한다.
- [ ] 자동차는 0에서 9 사이의 값 중 4 미만이면 멈춘다.
- [ ] 자동차가 여러 번 전진하면 전진한 횟수만큼 위치가 증가한다.
- [ ] 이동 값이 0에서 9 사이가 아닐 경우 예외를 발생시킨다.

### 자동차 목록
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- [ ] 각 자동차의 이름은 중복될 수 없다.
- [ ] 빈 이름이 포함된 경우 예외를 발생시킨다.

### 자동차 경주
- [ ] 시도 횟수는 1 이상이어야 한다.
- [ ] 라운드를 진행하면 남은 시도 횟수가 감소한다.
- [ ] 남은 시도 횟수가 0이면 게임이 종료된다.
- [ ] 종료된 게임에서 라운드를 진행하면 예외를 발생시킨다.

### 우승자
- [ ] 가장 멀리 간 자동차가 우승한다.
- [ ] 우승자가 여러 명일 경우 모두 반환한다.
- [ ] 우승자가 없을 경우 예외를 발생시킨다.
